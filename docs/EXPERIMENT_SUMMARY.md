# 실험·결과·분석 종합 — EVA-X Tiny의 흉부 X-ray 확률 보정(calibration)

팀이 수행한 **모든 실험과 결과, 분석**을 한 곳에 모은 문서입니다. 숫자는 각 실험 문서에서 옮겼고 출처 링크를 함께 달았습니다.
최종 업데이트: 2026-10-27.

---

## 0. 요약

> **"calibration을 좌우한 것은 학습 방법보다 라벨의 출처였다."**

1. 13가지 학습 방법을 비교했지만, 미리 정한 주 평가에서는 **어떤 방법도 기준 모델(baseline)을 넘지 못했다.**
2. 원인 분석 결과, 학습용 판독문 라벨과 평가용 전문가 라벨의 **질환 유병률이 최대 2.6배 달랐고**, 주 평가의 calibration 오차(ECE)는 **대부분 이 차이로 설명된다.**
3. 전문가 라벨 일부로 보정 방법만 Platt으로 바꿔도 baseline의 ECE가 **0.117 → 0.085**로, 가장 좋았던 학습 방법(Mixup+TS 0.105, LoRA+TS 0.092)보다 낮아졌다.

## 1. 배경

### 1.1 Calibration이란
- 모델이 내는 확률이 실제 빈도와 맞는 정도. 예측 확률 70%인 영상 100장 중 약 70장이 실제 양성이면 잘 보정된 모델.
- **AUROC**는 환자와 비환자를 "순서대로" 잘 나누는지만 본다. 확률값 자체가 맞는지는 보지 않는다. 그래서 AUROC가 높아도 확률이 크게 틀릴 수 있다.
- 임상에서 확률을 근거로 판단하려면(예: 위험도 30% 이상이면 추가 검사) calibration이 중요하다.

### 1.2 데이터: CheXpert (Stanford)
- 흉부 X-ray, 5개 질환: **Atelectasis(무기폐), Cardiomegaly(심비대), Consolidation(경화), Edema(부종), Pleural Effusion(흉수)**.
- **train 라벨 = 판독문에서 자동 추출**(NLP labeler). 양성/음성/**불확실(-1)**/미언급이 있음.
- **공식 valid 라벨 = 영상의학 전문의 합의 판독**. 정면 영상 202장, 환자 200명. 이 연구의 최종 test.
- 사용한 분할(환자 단위, 겹치는 환자 없음):

| 분할 | 영상 | 환자 | 라벨 | 용도 |
|---|---:|---:|---|---|
| train | 172,066 | 58,082 | 판독문 | 학습 |
| dev | 9,152 | 3,226 | 판독문 | 체크포인트 선택 |
| calibration | 9,809 | 3,226 | 판독문 | 주 평가의 TS 보정 |
| test (공식 valid) | 202 | 200 | 전문가 | 최종 평가 |

### 1.3 모델: EVA-X
- 흉부 X-ray 52만 장으로 자기지도 사전학습한 Vision Transformer (hustvl, npj Digital Medicine 2025).
- 이번 연구는 가장 작은 **EVA-X Tiny(6M 파라미터)**를 사용했다. 사전학습 가중치에서 시작해 직접 fine-tuning했다.
- 서버: 병원 내 GPU 서버(NVIDIA L4 × 4), 외부 인터넷이 차단된 환경.

## 3. 실험별 결과 (E0~E3)

### 3.1 E0. 공개 가중치 평가 — 출발점

EVA-X 저자들이 공개한 CheXpert 학습 완료 모델. 추가 학습 없이 test 202장으로 평가했다.

| 모델 | mAUROC | Brier | NLL | ECE@10 | Cardiomegaly ECE@10 |
|---|---:|---:|---:|---:|---:|
| Tiny | 0.8958 | 0.1397 | 0.4429 | 0.1278 | 0.2394 |
| Small | **0.9012** (논문 90.1과 일치) | 0.1352 | 0.4329 | 0.1087 | 0.2226 |

- 판별력(AUROC)은 높지만 **Cardiomegaly는 두 모델 모두 확률 오차(ECE)가 0.22~0.24로 가장 컸다.** 이것이 calibration 연구의 출발점이었다.

### 3.2 E1. 예비 실험: BCE vs label smoothing

본 실험 전에 파이프라인과 방향을 확인한 실험이다. Tiny 사전학습 가중치에서 시작해 5 epoch(GPU 4 × batch 128), seed 0으로 학습했다. **TS는 적용하지 않았다.**

| 지표 | BCE | Label smoothing | 차이 |
|---|---:|---:|---:|
| mAUROC | 0.8805 | 0.8806 | +0.0001 |
| Brier | 0.1345 | 0.1331 | −0.0014 |
| NLL | 0.4252 | 0.4163 | −0.0089 |
| ECE@5 | 0.0947 | 0.0882 | −0.0066 |
| ECE@10 | 0.1106 | 0.1154 | +0.0048 |

- AUROC는 같고 Brier와 NLL은 약간 좋아졌지만, ECE는 구간 수에 따라 방향이 갈렸다.
- 이 결과를 바탕으로 비교 대상을 여러 축으로 넓히고, TS를 공통으로 적용하는 본 실험(E2)을 설계했다.

### 3.3 E2. 본 실험 설계

**공통 설정**: EVA-X Tiny 사전학습 가중치에서 시작, seed 0, GPU 4 × batch 256, AdamW(LR 0.001), 최대 10 epoch(최소 5 epoch 이후 dev AUROC가 2번 연속 개선되지 않으면 종료), dev AUROC 최고 체크포인트 선택. 모든 조건에 **질환별 Temperature Scaling(TS)**을 적용했다.

**baseline**: 전체 fine-tuning + BCE loss + 원본 불확실 라벨 처리(Atelectasis·Edema는 0.7~0.8, 나머지는 0.2~0.3의 soft target).

**비교 조건** — baseline에서 한 가지만 바꿈:

| 축 | 조건 | 무엇을 바꿨나 |
|---|---|---|
| **C. 학습 범위** | Head만 | 분류 층만 학습 |
| | 마지막 2 block | 마지막 Transformer block 2개 + 분류 층만 학습 |
| | LoRA | 저랭크 어댑터(rank 8)만 학습 |
| **B. 불확실 라벨(-1)** | U-Ones | 불확실 → 양성(1) |
| | U-Zeros | 불확실 → 음성(0) |
| | U-Ignore | 불확실 라벨은 loss에서 제외 |
| | Soft U | 불확실 → 0.55~0.85 사이 soft target |
| **A. 학습 방법** | Label smoothing | 정답 0/1을 0.025/0.975로 부드럽게 (ε=0.05) |
| | Focal loss | 어려운 샘플에 가중치 (γ=2) |
| | MDCA | 평균 예측 확률과 평균 정답의 차이를 loss에 추가 |
| | Mixup | 두 영상과 라벨을 섞어 학습 (α=0.2) |
| | SPA+LPR | 다중 라벨 calibration용 loss (CVPR 2024) |
| **조합** | dev 기준 자동 선택 | 결과적으로 U-Ignore와 같은 설정이 선택됨 |

**두 가지 평가 방식** (TS를 어떤 라벨로 맞추느냐의 차이):

| 평가 | TS를 맞추는 데이터 | 평가 데이터 | 역할 |
|---|---|---|---|
| **주 평가** (report_holdout) | calibration 분할 (**판독문** 라벨) | test 202장 전체 | 실험 전에 미리 정한 기준 |
| **보조 평가** (expert_subset) | test 환자 절반 (**전문가** 라벨) | 나머지 절반 (약 100장) | 보조 확인 |

두 평가는 평가 영상이 달라서 **서로의 숫자를 직접 비교하면 안 된다.**

### 3.4 지표 읽는 법
- **AUROC ↑**: 환자와 비환자를 구분하는 능력 (0.5 = 무작위, 1 = 완벽).
- **ECE ↓**: 예측 확률과 실제 비율의 평균 차이. 10개 구간 기준(ECE@10). 0이면 완벽한 calibration.
- **Brier ↓**, **NLL ↓**: 확률 예측의 전반적 품질 (판별력 + calibration).
- 모든 숫자는 5개 질환의 평균(macro)이다.

|---|---|---:|---:|---:|---:|
| 기준 | **Baseline** | 0.8868 | 0.1431 | 0.4510 | **0.1169** |
| C | Head만 | 0.8709 | 0.1559 | 0.4803 | 0.1281 |
| C | 마지막 2 block | 0.8859 | 0.1423 | 0.4499 | 0.1215 |
| C | LoRA | 0.8795 | 0.1460 | 0.4543 | 0.1206 |
| B | U-Ones | 0.8837 | **0.1365** | **0.4328** | 0.1221 |
| B | U-Zeros | 0.8773 | 0.1570 | 0.4825 | 0.1282 |
| B | U-Ignore | 0.8779 | 0.1444 | 0.4580 | 0.1177 |
| B | Soft U | 0.8845 | 0.1427 | 0.4479 | 0.1236 |
| A | Label smoothing | 0.8867 | 0.1445 | 0.4543 | 0.1218 |
| A | Focal | 0.8865 | 0.1435 | 0.4529 | 0.1242 |

- U-Ones는 Brier와 NLL이 가장 좋다. Mixup은 AUROC가 가장 높지만 차이가 0.0002로 매우 작다.

## 4. 원인 분석 (E4)

### 4.1 라벨 출처에 따라 유병률이 크게 다르다

| 질환 | 판독문 라벨 (train) | 전문가 라벨 (test) | 배수 |
|---|---:|---:|---:|
| Atelectasis | 18.5% | **37.1%** | ×2.0 |
| Cardiomegaly | 12.6% | **32.7%** | ×2.6 |
| Consolidation | 7.8% | **15.8%** | ×2.0 |
| Edema | 27.8% | 20.8% | ×0.75 |
| Pleural Effusion | 42.4% | 31.7% | ×0.75 |

(판독문 라벨은 불확실(-1)을 제외하고 미언급을 음성으로 센 값.)

### 4.2 모델은 판독문 기준에 맞춰져 있어서, 전문가 기준으로는 크게 과소 예측한다

baseline+TS(주 평가)의 질환별 **평균 예측 확률 − 실제 유병률**:

| Atelectasis | Cardiomegaly | Consolidation | Edema | Pleural Effusion |
|---:|---:|---:|---:|---:|
| **−0.163** | **−0.226** | −0.093 | +0.055 | −0.029 |

- 이 차이의 절댓값 평균은 **0.113**이고, 같은 모델의 ECE@10은 **0.117**이다. **주 평가의 calibration 오차 대부분이 이 평균 차이로 설명된다.**
- TS는 확률의 "기울기"만 조정해서 이 평균 차이(절편)를 옮기지 못한다. 판독문 라벨로 맞추는 한, 어떤 사후 보정도 이 차이를 고칠 수 없다.
  - 실제로 판독문 라벨 기반 TS는 보정 전과 차이가 없었다(ΔECE +0.002, 95% CI가 0 포함).
- → **13개 학습 방법이 주 평가에서 효과가 없었던 이유는 방법 자체보다 평가 라벨과 보정 라벨의 분포 차이일 가능성이 크다.**

### 4.3 전문가 라벨로 보정할 수 있다면: Platt이 TS보다 낫다

**Platt scaling** = 질환별로 기울기와 **절편까지** 조정하는 보정 방법. TS와 같은 데이터로 맞췄다.

보조 평가, 15개 run 평균, TS 대비 차이(괄호는 환자 bootstrap 95% CI):

| | ΔBrier | ΔNLL | ΔECE@10 | ΔAdaptive ECE@10 |
|---|---|---|---|---|
| Platt − TS | **−0.015** [−0.026, −0.005] | **−0.041** [−0.065, −0.016] | −0.026 [−0.033, +0.005] | **−0.040** [−0.051, −0.016] |

조건별 ECE@10 (보조 평가):

| 조건 | TS | **Platt** |
|---|---:|---:|
| Baseline | 0.117 | **0.085** |
| Mixup | 0.105 | 0.088 |
| LoRA | 0.092 | 0.076 |
| U-Ones | 0.112 | 0.077 |

- **baseline에 Platt만 적용해도(0.085) 가장 좋았던 학습 방법+TS(Mixup 0.105, LoRA 0.092)보다 ECE가 낮다.**
- Platt 기준에서는 **Mixup의 ECE 이점이 사라진다**(0.088 vs baseline 0.085). Mixup의 ECE 개선은 TS가 절편을 못 옮겨서 생긴 차이였을 수 있다. 단, Mixup의 AUROC 우위는 보정 방법과 무관하다.
- 라벨 없이 유병률만 대입하는 보정(prior shift)은 효과가 없었다. loss를 바꾼 모델들은 원래 분포에서도 보정이 맞지 않기 때문이다.

## 5. 결론과 한계

### 결론
1. 판독문 라벨로 학습하고 보정한 모델은 전문가 라벨 기준으로 확률이 체계적으로 어긋난다. 그 주된 원인은 **질환 유병률 차이**다.
2. 이 상황에서는 학습 방법(loss, 학습 범위, 불확실 라벨 처리)을 바꾸는 것보다 **목표 분포의 라벨로, 절편까지 보정하는 것**이 더 효과적이었다.
3. 학습 방법 중에서는 Mixup(AUROC)과 LoRA, U-Ones(확률 품질)가 후보지만, 재현성 확인이 필요하다.

### 한계
- **seed 1개.** 학습 방법 간 작은 차이(AUROC 0.4%p 등)는 우연일 수 있다.
- **평가 데이터가 작다.** 주 평가 202장, 보조 평가 약 100장. 보조 평가의 환자 분할도 한 번만 했다.
- Platt의 ECE@10 개선은 CI가 0을 근소하게 포함한다. 미리 정한 판정 기준으로는 **"부분적 지지"**다.
- 전문가 라벨로 보정하려면 실제 배포 환경에서도 전문가 라벨이 일부 필요하다.
- EVA-X Tiny 하나만 썼다. 외부 데이터(MIMIC-CXR 등) 검증은 하지 않았다.
- 공개 Tiny(0.896)와 직접 학습한 baseline(0.887)은 학습 조건이 달라서 직접 비교하지 않는다.

## 6. 용어 정리

| 용어 | 설명 |
|---|---|
| Calibration | 예측 확률과 실제 빈도가 일치하는 정도 |
| AUROC | 양성과 음성을 순서대로 구분하는 능력. 확률값 자체는 보지 않음 |
| ECE (Expected Calibration Error) | 확률 구간별 \|평균 예측 − 실제 양성 비율\|의 가중 평균. 10구간 = ECE@10 |
| Adaptive ECE | 구간을 등간격이 아니라 샘플 수가 같도록 나눈 ECE |
| Brier score | (예측 확률 − 정답)²의 평균 |
| NLL | 정답에 준 확률의 −log 평균. 틀린 확신에 큰 벌점 |
| Temperature Scaling (TS) | logit을 T로 나누는 사후 보정. 기울기만 조정. 질환별로 T를 따로 맞춤 |
| Platt scaling | 질환별로 a·logit + b. 기울기와 절편을 모두 조정 |
| 유병률 (prevalence) | 데이터에서 해당 질환 양성의 비율 |
| 불확실 라벨 (-1) | 판독문에 "가능성 있음"처럼 애매하게 적혀 자동 추출이 불확실로 분류한 라벨 |
| LoRA | 큰 가중치는 고정하고 작은 저랭크 행렬만 학습하는 방법 |
| Mixup | 두 영상과 라벨을 비율대로 섞어 만든 가상 샘플로 학습 |
| Patient bootstrap CI | 환자를 복원추출로 다시 뽑아 계산한 95% 신뢰구간 |
