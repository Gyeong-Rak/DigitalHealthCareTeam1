# 유병률 차이와 사후 보정 방법 분석 (seed 0, 학습 없음)

계획과 사전 판정 기준: [VERIFICATION_PLAN.md](VERIFICATION_PLAN.md) 실험 1. 기존 결과: [README.md](README.md).

## 실험 내용

- 목적: 주 평가(report_holdout)에서는 어떤 조건도 baseline+TS를 넘지 못하고 보조 평가(expert_subset)에서만 개선이 보인 이유를 설명하고, 질환별 TS 외의 사후 보정이 결론을 바꾸는지 확인.
- 대상: `tiny_study_seed0`의 14조건과 추가 조합(`tiny_study_lora_mixup_ignore`), 모두 seed 0. **새 학습·추론 없음.** 저장된 logits만 사용.
- 보정 방법(질환별). 기존 TS와 **같은 fitting 데이터·같은 평가 데이터**를 사용하며, fitting NLL이 나빠지면 항등 변환으로 되돌립니다.

| 방법 | 식 | 비고 |
|---|---|---|
| ts | sigmoid(z / T) | 기존 질환별 TS, 15개 run 모두 기존 수치 재현 확인 |
| bias | sigmoid(z + b) | 절편만 |
| platt | sigmoid(a·z + b) | 기울기 + 절편 |
| prior | sigmoid(z + logit(π_fit) − logit(π_report)) | 라벨 없이 유병률만 사용, expert_subset에만 해당 |

- 모두 단조 변환이라 AUROC는 바뀌지 않습니다. 비교 지표는 Brier·NLL·ECE@10·Adaptive ECE@10(macro)입니다.
- 괄호는 평가 환자 단위 paired bootstrap 95% CI(1000회)입니다. 15개 run의 차이 평균을 같은 resample에서 계산했습니다.
- 스크립트: `scripts/analyze_calibration_shift.py`.

## 해석

**주 평가에서 개선이 없던 주된 이유는 라벨 출처에 따른 유병률 차이로 보입니다.** 판독문 라벨 대비 전문가 라벨에서 Atelectasis·Cardiomegaly·Consolidation 유병률이 약 2~2.6배입니다. 모델은 판독문 분포에 맞춰져 있어 전문가 라벨 기준으로 이 질환들을 크게 과소 예측하며, 주 평가 ECE의 대부분이 이 평균 차이로 설명됩니다. 판독문 라벨로 fitting하는 사후 보정은 이를 고칠 수 없습니다. TS는 raw와 차이가 없고, 절편 보정은 판독문 분포 쪽으로 더 맞춰 오히려 나빠졌습니다. 따라서 14개 학습 방법이 주 평가에서 baseline을 넘지 못한 결과는 방법 자체의 한계라기보다 **평가 라벨과 보정 라벨의 분포 차이**를 반영할 가능성이 큽니다.

**전문가 라벨로 fitting할 수 있으면 Platt가 TS보다 낫습니다.** Brier·NLL·Adaptive ECE@10에서 CI가 0을 포함하지 않는 개선을 보였습니다. 다만 사전에 정한 기준인 ECE@10의 CI 상한 < 0은 근소하게 충족하지 못했으므로(상한 +0.0049) **부분적 지지**로 기록합니다. 사전 기준에서 예상한 "유병률 변화가 큰 질환" 중 Cardiomegaly는 맞았으나 두 번째로 큰 오차는 Consolidation이 아니라 Atelectasis였습니다. 계획 작성 시 참고한 EVA-X 로그는 Atelectasis의 불확실 라벨을 양성으로 셌기 때문입니다.

**기존 결론 중 ECE 관련 부분은 보정 방법에 따라 달라집니다.** expert_subset에서 baseline+Platt(ECE@10 0.085)는 Mixup+TS(0.105)와 LoRA+TS(0.092)보다 낮습니다. Platt 기준에서는 Mixup의 ECE 이점이 사라지고(0.088 vs baseline 0.085), LoRA는 소폭 낮은 상태(0.076)가 유지됩니다. **Mixup의 ECE 개선은 TS가 절편을 옮기지 못하는 데서 생긴 차이일 수 있습니다.** Mixup의 AUROC 우위(0.907 vs 0.903)는 보정 방법과 무관하며 seed 반복으로 확인할 대상입니다.

**라벨 없는 prior 보정은 효과가 없었습니다.** 모델이 원래 분포에서 잘 보정돼 있다는 가정이 필요한데, loss를 바꾼 조건에서는 이 가정이 깨집니다(focal 0.234).

## 한계

- seed 1개. 학습 방법 간 차이의 재현성은 실험 2(seed 반복)에서 확인합니다.
- expert_subset은 환자 50:50 무작위 분할 한 번이며 평가가 약 100장·100명입니다. 분할에 따른 변동은 아직 반영하지 않았습니다. 조건별 Δ(vs baseline)의 CI도 아직 계산하지 않았습니다.
- CI는 평가 환자 표본의 불확실성만 반영하며, 같은 평가 집합을 여러 비교에 사용했습니다(다중 비교 보정 없음).
- Platt는 질환별 모수가 2개라 fitting 표본이 작을 때 과적합 위험이 있습니다. 평가는 분리된 절반에서 했으므로 위 개선은 표본 밖 결과입니다.
- 전문가 라벨로 보정하려면 배포 환경에서도 전문가 라벨이 일부 필요합니다. 이것은 별도의 비용입니다.
- 수치는 서버에서 원본 예측 배열로 다시 계산한 결과이며, 이 문서에는 생성된 보고서를 옮겼습니다.
